# 监控视角 · 猫狗睡眠数据采集工具集（V4）

本仓库是「监控视角猫狗睡眠数据采集与标注（V4 规范）」的**配套工具与目录骨架**，用于管理图片配额、采集台账、查重与合规校验，并附带一个基于开放版权图库（Wikimedia Commons）的素材构建 / 质检工具，方便在正式实拍前做流程验证。

> ⚠️ **本仓库不包含任何图片素材。** 图片体积大、且涉及来源与授权，需按规范自行采集后放入 `dataset/` 对应类别目录；素材不入版本库（见 `.gitignore`）。

## V4 规范关键要求（摘要）

| 维度 | 要求 |
|---|---|
| 分辨率 | 原始分辨率 **≥ 1280×720**；不插值放大 / 美颜 / 拼接；不以贴脸特写替代家监场景 |
| 画幅 | **全部横屏**（宽 > 高，优先 16:9） |
| 光照 | 日间亮 **40%** / 日间暗 **10%** / 夜间开灯 **20%** / 夜间关灯红外 **30%** |
| 距离 | 近景(≤2m) **20%** / 中景(2–4m) **60%** / 远景(>4m) **20%** |
| 上下机位 | 仰拍 5% / 近似平视 25% / 斜俯拍 50% / 近似正上方 20% |
| 水平方向 | 前 / 侧 / 后 / 前斜 / 后斜 各 20% |
| 多宠 | 单宠 70% / 同物种多宠 20% / 猫狗同框 10% |
| 困难场景 | 毛色近似背景、身体被遮挡 各 ≥ 5% |
| 卧姿眼部覆盖 | 可辨闭眼 ≥ 50% / 睁眼含微睁 ≥ 20% / 两眼不可见 ≥ 10% / 看不清 ≤ 2% |
| 卧姿子姿态 | 蜷卧 / 仰卧 / 侧卧 / 趴卧 |
| 非卧姿子姿态 | 坐姿 / 站姿 / 蹲伏低伏 / 前低后高 / 后肢直立 |
| 计数规则 | 每只入画宠物最多约 10 张；不以连拍 / 裁剪 / 改名重复计数；每图只选一只主对象 |

> 图片来源可为：家监截图 / 录像抽帧 / 手机横拍（**地点不限定在家**）。
> 夜间关灯红外须**设备原生成像**，不得调灰伪造。

## 工具用法

### 1. 采集与合规工具 `collection/collection_tool.py`

依赖：Python 3 + Pillow。数据全部留在本机。

```bash
cd collection

# 生成配额表、台账模板、实拍目录（首次）
python collection_tool.py init

# 扫描照片 → 更新台账 → 查重 / 合规检查 → 生成看板与报告
python collection_tool.py check

# 生成少量模拟数据，用于验证工具本身（可随时删除）
python collection_tool.py demo
```

产出：
- `采集台账.csv` —— 逐张台账（含感知哈希、重复组、文件状态，以及 V4 标注字段）
- `合规报告.txt` —— 配额进度、分布占比、问题清单
- `配额看板.html` —— 可视化看板

> 若照片不在默认 `实拍图片/`，可指定：
> `IMS_PHOTO_DIR="D:/我的照片" python collection_tool.py check`

### 2. 素材构建 / 质检 `image-meta-studio/`

```bash
python image-meta-studio/dataset_builder.py   # 从 Wikimedia Commons 抓取开放授权素材
python image-meta-studio/server.py            # 启动本地 Web 界面（或双击 启动.pyw）
```

`dataset_builder.py` 已内置：分辨率 ≥1280×720、强制横屏、感知哈希去重、`不带人` / `非绘画` / 姿态语义过滤等。

## 采集流程建议

1. `python collection_tool.py init` 生成配额与目录；
2. 按 V4 配比实拍 / 抽帧，放入 `collection/实拍图片/`（或 `dataset/` 分类目录）；
3. `python collection_tool.py check` 出报告，按提示补齐配额与分布；
4. 按台账逐张补全 V4 标注字段（子姿态 / 左右眼状态 / 光照 / 机位 / 方向 / 距离 / 多宠 / 困难场景等）；
5. 重点补 **夜间关灯红外（约 30%）**——网图与普通照片无法替代，必须设备实拍。

## 备注

- `dataset_builder.py` 抓取的是 **Wikimedia Commons 开放授权**图片，仅作前期流程验证与素材参考；**不能直接按 V4 提交**，仍需逐张人工标注，且夜间红外需实拍补齐。
- 工具在 Windows / Python 3.x 下开发，`collection_tool.py` 仅依赖 Pillow。
