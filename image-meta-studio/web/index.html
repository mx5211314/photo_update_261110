使用说明

三步走

  1. 左侧选目录 → 扫描（或直接拖图片进来）。
  2. 点「按目录 / 来源清单自动填充」一次性写入类别、姿态、编号、作者、授权、来源页；也可以点「AI 生成」补标题/描述/关键词，或逐张编辑、批量套用。
  3. 设置输出规格（如 16:9 / 1920 × 1080）→ 点「转换为带元数据的图片」。结果在新目录，附 CSV / JSON 台账。

元数据都写到哪

JPEG / WebP / TIFF：EXIF（含 Windows XP 系列 UTF-16 标签）+ XMP APP1；PNG：tEXt / iTXt 文本块 + XMP。中文走 UTF-16 与 XMP，不会被 EXIF 的 ASCII 字段截断。自定义字段写入 XMP 的 ims: 命名空间与台账。

尺寸模式

补边等比缩放后加纯色边，画面完整；裁剪等比放大后居中裁切，铺满目标；拉伸精确到像素但会变形；不调整只写元数据。

要固定 16:9：在「画面比例」里选 16:9，只填宽度高度就自动算好；点「一键 16:9 · 裁剪铺满」直接得到满幅成品。标准 16:9 尺寸为 1920×1080 / 1600×900 / 1280×720 / 960×540，1080×720 是 3:2。

安全约定

输出默认写到输入目录下的 _ImageMeta_输出，同名文件自动加序号，绝不覆盖原图。服务只监听 127.0.0.1，图片与密钥都不上传。

AI 接口

兼容 OpenAI 视觉消息格式（image_url + base64）。本机网关例如 http://127.0.0.1:xxx/v1 也可以填。失败会自动离线兜底并在报告里列出原因。
